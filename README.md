# ForceEthernetWiredIcon
A simple windhawk mod that forces Windows 11 or StartAllBack to use the Ethernet/Wired icon compared to the default Wi-FI icon



_____________ How To Set-Up _____________________


1) Download ForceEthernetWindhawkMod.cpp from the respository or go to Code > Download Zip
2) Install Windhawk
3) Go to the home page of Windhawk and click the "Create a New Mod" button at the bottom right of the screen
4) Paste all the code from ForceEthernetWindhawkMod.cpp
5) Click Compile Mod then Preview Mode when it finishes
6) Go back to Windhawk's homescreen and make sure the mod is on
7) Restart explorer.exe in task manager and Windows should now display the Ethernet Icon
